# HelloWorld (hMod)

> **⚠️ Note:**
> This plugin template is **exclusively** designed for hMod.
> It is dedicated to hardcore geeks exploring the ancient **Minecraft Alpha** version.

This is an example plugin for hMod.

## Build 

Please choose the build tool according to your preference:

* **if you're a Gradle user:**
```bash
./gradlew clean build
```
(output: `build/libs/yourPluginName.jar`)

* **else if you're a Maven user:**
```bash
mvn clean package
```
###### or use `mvnd clean package` for a lighting-fast build!
(output: `target/yourPluginName.jar`)

* **else if you're Hardcore Geek**
```bash
ant clean build
```
(output: `target/libs/yourPluginName.jar`)
